# Belajar Git & GitHub

Repository praktik untuk mempelajari dasar Git dan GitHub.

## Tujuan

Setelah menyelesaikan praktik ini, kamu diharapkan memahami:

- Repository
- Clone
- Branch
- Commit
- Push
- Pull Request
- Code Review
- Merge

## Aturan

1. Jangan langsung bekerja di branch `main`.
2. Setiap perubahan dibuat melalui branch.
3. Gunakan commit message yang jelas.
4. Perubahan dikirim melalui Pull Request.
5. Pull Request harus direview sebelum di-merge.
