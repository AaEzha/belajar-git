# Contribution Guide

## Langkah

1. Clone repository.
2. Buat branch baru.
3. Lakukan perubahan.
4. Commit perubahan.
5. Push branch ke GitHub.
6. Buat Pull Request.
7. Tunggu review.
8. Perbaiki jika ada feedback.
9. Merge setelah disetujui.

## Commit Message

Gunakan format:

<jenis>: <deskripsi>

Contoh:

docs: add student profile
docs: update activity description
fix: correct typo
